# Telegram-бот для приёма заявок в канал

Бот на `aiogram`, который автоматически одобряет заявки на вступление в закрытый Telegram-канал, сохраняет данные пользователей в MySQL и сообщает администратору о подозрительном наплыве вступающих. Администратор прямо в чате решает, выгнать ли недавно вступивших.

## Возможности

- Автоматическое одобрение заявок на вступление в канал
- Личное сообщение пользователю: «Ваша заявка была одобрена»
- Запись каждого вступившего (Telegram ID и имя) в базу данных MySQL
- Учёт вступлений по часам: для каждого часа создаётся своя таблица
- Оповещение администратора, если за один час аномальное количество человек (по вашему мнению)
- Кнопки в сообщении администратору:
  - **Да**: выгнать недавно вступивших
  - **Нет**: отменить действие
  - **Вывести пользователей**: показать список вступивших за текущий час
- Исключение пользователя без вечного бана: бот банит и сразу разбанивает, поэтому человек может вступить снова

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Добавь бота в канал как **администратора** с правами на приглашение и блокировку пользователей.
3. Включи в канале вступление по заявкам.
